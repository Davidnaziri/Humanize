# Humanize

A Codex skill for drafting, rewriting, polishing, translating, and proofreading text in your natural voice.

The skill preserves meaning and facts while avoiding formulaic language, inflated wording, repetitive structures, robotic tone, unnecessary formatting, and fabricated references. It includes a final review checklist.

## Install

Copy the `humanize` folder into your Codex skills directory, usually `~/.codex/skills/`. The resulting file should be `~/.codex/skills/humanize/SKILL.md`.

Restart Codex to load the skill.

## Use

Ask Codex to use the `humanize` skill when writing or editing text, for example:

> Use humanize to polish this email while keeping my meaning and tone.

See [the full skill instructions](humanize/SKILL.md).
